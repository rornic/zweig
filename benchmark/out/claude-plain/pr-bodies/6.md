## Replace REST polling with WebSocket push for live status dashboard

### Summary

The status dashboard currently polls `GET /api/status` every 2s per connected client to stay "live." At current usage this generates a steady, avoidable load on the backend that scales linearly with open dashboard tabs, most of which return unchanged data. This PR replaces polling with a WebSocket connection that pushes status updates only when state actually changes.

### Changes

- Added a WebSocket endpoint (`/ws/status`) that clients connect to on dashboard load.
- Backend now emits a status event to connected sockets whenever the underlying state changes, instead of clients pulling on a timer.
- Client-side polling logic (`setInterval` + fetch loop) removed and replaced with a WebSocket client that updates dashboard state on incoming messages.
- Added automatic reconnect with backoff if the socket drops, falling back to a single REST fetch on reconnect to resync state (covers missed events during the gap).
- Kept the REST `GET /api/status` endpoint in place for initial page load and as a fallback for clients that can't establish a WebSocket (behind a feature flag).

### Why

Polling cost scales with connected clients regardless of how often status actually changes; push only sends data when there's something new, and idle connections cost effectively nothing. This meaningfully cuts request volume and DB/cache load on the backend as dashboard usage grows, and also reduces perceived latency for status changes (push is near-instant vs. up to one poll interval of delay).

### Testing

- Verified dashboard receives live updates with multiple tabs open, and load on the backend drops accordingly compared to polling.
- Killed the server mid-session to confirm client reconnect + resync behavior works and doesn't leave the dashboard stale.
- Confirmed fallback to REST polling still works when the feature flag is disabled.

### Follow-ups

- Consider removing the REST fallback path once WebSocket rollout is confirmed stable in production.

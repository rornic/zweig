## Summary

- Bump `winston` from `3.x` to `4.0.0`
- Migrate `format.simple()` config to the new `format.combine()` pipeline required by v4
- Update the two custom transports (`SlackTransport`, `AuditTransport`) to the v4 transport interface

Winston 4 drops the implicit default formatter, so a logger created without an explicit `format` now throws at construction instead of silently falling back to `simple()`. All our loggers relied on that fallback, so every call site needed an explicit `format.combine(format.timestamp(), format.json())` or equivalent.

Transport constructors also changed. `log(info, callback)` is now `log(info)`, returning a `Promise`. Callback-based error handling is gone in favor of transport-level `error` events. Both custom transports now match this interface. Callers of `logger.add()` are unaffected.

No other breaking changes in v4 apply to our usage (`v3` deprecations around `.cli()` and `.padLevels` were already unused here).
